# Heart Animation

A beautiful glowing heart particle animation created using JavaScript, HTML, and CSS.  
The animation forms a sparkling heart shape made of thousands of tiny particles on a dark background.

## ✨ Features

- Smooth particle-based heart animation
- Minimal dark aesthetic
- Lightweight and responsive
- Built with pure HTML, CSS, and JavaScript
- Perfect for creative landing pages or romantic-themed projects

## 📸 Preview

The animation displays a glowing pink heart made of animated particles with a soft cinematic feel.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
